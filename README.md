# CloudMusic2KTV

CloudMusic2KTV 是一个本地运行的个人练唱工具：从网易云音乐取得当前账号有权播放的歌曲素材，并生成带封面、动态频谱和歌词扫色的 KTV 视频。

整个操作都在浏览器 WebUI 中完成，主要功能由 Python 实现。

> 本项目仅用于处理你依法有权访问的内容以及个人练唱。请遵守网易云音乐的服务条款和当地法律，不要传播生成的音频、歌词或视频。

## 当前功能

- 手机号 + 短信验证码登录网易云音乐；
- 不同浏览器使用独立的网易云登录会话，歌曲素材和视频队列共享；
- 使用登录账号现有的网页播放权益，包括账号有权完整播放的 VIP 歌曲；
- 通过歌曲 ID、网易云歌曲链接或“歌名 + 歌手”搜索歌曲；
- 下载并校验完整音频、高清封面和歌词；
- 保存原文、翻译、罗马音、卡拉 OK 原始歌词以及统一的毫秒时间轴；
- 在生成前预览实际视频画面；
- 生成 720p 或 1080p、30 FPS、H.264/AAC MP4 视频；
- 支持多种背景、歌词模式、扫色颜色、画质和动态频谱设置；
- 自动处理开场动画、开头静音预卷、长间奏留白和间奏结束倒计时。

## 运行要求

- Windows 10/11（当前视频字体回退逻辑使用 Windows 自带的中日文字体）；
- Python 3.11 或更新版本；
- 可以正常访问 `music.163.com` 的网络；
- 网易云音乐账号；VIP 歌曲需要该账号本身拥有相应播放权益；
- 足够的磁盘空间。音频、频谱缓存、预览图和最终视频都会保存在本地。

生成视频主要消耗 CPU。1080p、高画质和较长歌曲可能需要数分钟到数十分钟，具体取决于电脑性能。

## 安装与启动

在 PowerShell 中进入项目目录，然后执行：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

浏览器打开：<http://127.0.0.1:7860/>

项目默认只监听本机地址 `127.0.0.1`。通常不需要单独安装 FFmpeg，`imageio-ffmpeg` 会提供视频编码所需的可执行文件。

如果 PowerShell 不允许执行激活脚本，也可以不激活环境，直接运行：

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

可通过环境变量修改监听地址和端口：

```powershell
$env:CLOUDMUSIC2KTV_HOST = "127.0.0.1"
$env:CLOUDMUSIC2KTV_PORT = "7860"
.venv\Scripts\python.exe app.py
```

临时允许同一局域网内的手机访问时，将监听地址设为 `0.0.0.0`，然后使用电脑的局域网 IPv4 地址访问：

```powershell
$env:CLOUDMUSIC2KTV_HOST = "0.0.0.0"
.venv\Scripts\python.exe app.py
```

这会同时暴露登录入口和本地视频文件，只应在可信网络中使用；不要把开发服务器直接长期暴露到公网。

## 使用方法

### 1. 登录网易云账号

在“01 网易云账号”中填写国家/地区代码和手机号，获取短信验证码后登录。

- 默认国家/地区代码为 `86`；
- 手机号和验证码不会写入磁盘；
- 浏览器只保存一个不可读的随机会话 Cookie；
- 真正的网易云 Cookie 按浏览器隔离保存在 `instance/sessions/`；
- 会话默认 90 天未使用后过期，服务启动和成功登录时会清理旧文件；
- 点击“退出”只删除当前浏览器对应的服务器会话文件。

`instance/sessions/` 中的文件相当于登录凭据，请勿分享或提交到公开仓库。可通过 `CLOUDMUSIC2KTV_SESSION_DAYS` 修改未使用会话的保留天数。

### 2. 选择歌曲

“02 选择歌曲”支持三种方式：

- 直接填写歌曲 ID，例如 `642810`；
- 填写网易云歌曲链接，例如 `https://music.163.com/#/song?id=642810`；
- 输入歌名、歌手进行搜索，然后点击正确的搜索结果。

修改 ID 输入框后必须点击“读取”或按 Enter 才会应用。03/04 区会跟随最后一次成功读取或点击选中的歌曲。页面刷新后会恢复最后选中的歌曲。已经完整保存在共享素材库中的歌曲会优先从本地 metadata 读取，不依赖当前登录或网易云网络。

### 3. 下载全部素材

选择音质后点击“下载全部素材”。可选音质包括：

- 标准；
- 较高；
- 极高；
- 无损；
- Hi-Res。

实际返回的格式和音质由网易云及当前账号权益决定。程序会使用网易云返回的信息校验音频大小，并在可用时校验 MD5。

视频预览和生成都依赖本地素材，因此每首新歌必须先完成这一步。选择歌曲时页面会显示共享素材状态；下载完成后同一区域会显示歌曲、歌手、实际音质和可用歌词类型，素材已存在时按钮变为“重新下载素材”。同一首歌同一时间只允许一个下载请求。

### 4. 投屏已有视频

“03 投屏已有视频”只扫描当前歌曲输出目录中的完整 `ktv_*.mp4`，不访问网易云。存在多个分辨率或配置时可以选择具体版本；“先测试播放”用于确认手机能读取视频。

点击“使用投屏应用打开”后，HTTPS 页面会打开系统分享菜单，可选择 BubbleUPnP。通过局域网 HTTP 地址访问时，浏览器通常不允许网页调用系统分享，按钮会改为复制视频网络地址；在 BubbleUPnP 中打开该地址后再选择 DLNA 播放设备。媒体接口支持 HEAD 和 HTTP Range，接收端无需携带网易云登录信息。

### 5. 设置并预览视频

“04 生成 KTV 视频”提供以下选项：

- 歌词：仅原文、原文 + 翻译、原文 + 罗马音；
- 背景：封面模糊、封面配色渐变、纯色、自定义图片；
- 扫色：默认蓝色、自动匹配封面、自定义颜色；
- 分辨率：1920 × 1080 或 1280 × 720；
- 视频画质：高画质、平衡、较小文件；
- 是否显示动态频谱及其强度；
- 是否显示自动开场动画；
- 是否在间奏结束前显示歌词提示。

设置变化后会自动更新预览，也可以点击“更新预览”。预览和完整视频使用同一套 Python 帧渲染器。

自定义背景会保存到当前歌曲的输出目录，并在之后继续使用，直到再次上传覆盖它。图片上传上限为 32 MiB。

### 6. 生成完整视频

确认 04 区显示的“当前视频歌曲”正确并登录账号，然后点击“加入生成队列”。登录状态只在提交时验证，任务进入队列后不再绑定账号。

点击后，本次任务会立即锁定当时的歌曲和视频选项。生成期间可以在 02 区选择另一首歌，但新选择只影响下一次生成，不会改变正在运行的任务。

当前视频任务单线程执行；所有浏览器共享页面上的队列状态。队列区域位于提交区下方，会显示当前任务的歌曲、进度、等待数量和最近完成结果；点击“等待 n”可查看当前任务及全部排队歌曲。完全相同且仍在运行/等待的任务会自动去重。生成期间请注意：

- 不要关闭运行 `app.py` 的终端；
- 不要重启后端服务；
- 刷新页面不会停止后台任务，刷新后可以继续查看全局队列状态；
- 队列和任务记录仍只存在于当前 Python 进程内，重启服务会丢失状态。

完整视频文件名包含视频选项哈希，因此同一歌曲和分辨率的不同配置不会互相覆盖。队列区域会提供最近完成视频的浏览器打开链接。

## 输出文件

每首歌曲保存在：

```text
outputs/<歌曲ID>_<歌手>_<歌名>/
```

目录可能包含：

```text
audio.mp3 / audio.flac / 其他实际音频格式
cover.jpg / cover.png
metadata.json
lyrics.lrc
lyrics_translated.lrc
lyrics_romanized.lrc
lyrics_karaoke_raw.lrc
lyrics_raw.json
lyrics_timeline.json
custom_background.png
spectrum_30fps.npz
video_preview_<选项哈希>.png
ktv_1080p_<选项哈希>.mp4 / ktv_720p_<选项哈希>.mp4
```

其中：

- `metadata.json`：标准化歌曲信息和网易云返回的音频信息；
- `lyrics_raw.json`：网易云歌词接口的原始响应，便于排查问题；
- `lyrics_timeline.json`：视频渲染使用的逐行毫秒时间轴；
- `spectrum_30fps.npz`：根据音频生成的频谱缓存；
- `video_preview_*.png`：不同设置生成的静态预览；
- `ktv_*.mp4`：最终视频。

## 歌词与间奏规则

网易云并非为每首歌提供逐字时间轴。本项目会优先使用带时间的逐行歌词，并在当前行的起止时间之间匀速扫色。

当前固定规则为：

- 相邻歌词开始时间超过 15 秒时视为间奏；
- 间奏中间不显示歌词；
- 上一句歌词扫色最长 8 秒；
- 下一段开始前 4 秒显示歌词与倒计时条；
- 开场动画为 4 秒；如果歌词开始过早，会在歌曲前添加 4 秒静音预卷并同步后移画面。

## 常见问题

### 预览提示“本地还没有这首歌的素材”

先在 02 区选择歌曲，然后点击“下载全部素材”。只读取歌曲信息并不会下载音频和歌词。

### VIP 歌曲无法取得完整音频

确认页面显示已登录，并确认该账号当前拥有这首歌的完整网页播放权益。退出后重新验证码登录也可能解决过期会话问题。

### 登录状态突然丢失

当前浏览器的服务器会话可能已过期或损坏。重新使用短信验证码登录即可，不要手工共享 `instance/sessions/` 中的文件。

### 视频生成很慢

逐帧画面由 Pillow 生成，再交给 FFmpeg 编码。可以选择 720p、“较小文件”，或关闭动态频谱来降低处理量。

### 中文或日文显示不正常

当前会依次使用 Windows 的微软雅黑、游ゴシック、Meiryo 等字体。请确认系统中存在可用的中日文字体。

### 网易云接口突然不可用

本项目使用网易云网页播放器所用的内部接口，这些接口可能随网站更新而变化。终端日志、`metadata.json` 和 `lyrics_raw.json` 可用于定位问题。

程序默认让网易云请求直连，不继承启动进程中的 `HTTP_PROXY`、`HTTPS_PROXY` 或 `ALL_PROXY`，避免无效本地代理导致 `music.163.com:443` 连接失败。如确实需要代理，应在代码中显式启用 `NeteaseClient(trust_env_proxy=True)` 并确认代理可用。
