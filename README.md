# CloudMusic2KTV

CloudMusic2KTV 是一个本地运行的个人练唱工具：从网易云音乐取得当前账号有权播放的歌曲素材，并生成带封面、动态频谱和歌词扫色的 KTV 视频。

整个操作都在浏览器 WebUI 中完成，主要功能由 Python 实现。

> 本项目仅用于处理你依法有权访问的内容以及个人练唱。请遵守网易云音乐的服务条款和当地法律，不要传播生成的音频、歌词或视频。

## 当前功能

- 手机号 + 短信验证码登录网易云音乐；
- 使用登录账号现有的网页播放权益，包括账号有权完整播放的 VIP 歌曲；
- 通过歌曲 ID、网易云歌曲链接或“歌名 + 歌手”搜索歌曲；
- 下载并校验完整音频、高清封面和歌词；
- 保存原文、翻译、罗马音、卡拉 OK 原始歌词以及统一的毫秒时间轴；
- 在生成前预览实际视频画面；
- 生成 720p 或 1080p、30 FPS、H.264/AAC MP4 视频；
- 支持多种背景、歌词模式、扫色颜色、画质和动态频谱设置；
- 自动处理开场动画、开头静音预卷、长间奏留白和间奏结束倒计时。

## 运行要求

- Windows 10/11（当前视频字体回退逻辑使用 Windows 自带的中日文字体）；
- Python 3.11 或更新版本；
- 可以正常访问 `music.163.com` 的网络；
- 网易云音乐账号；VIP 歌曲需要该账号本身拥有相应播放权益；
- 足够的磁盘空间。音频、频谱缓存、预览图和最终视频都会保存在本地。

生成视频主要消耗 CPU。1080p、高画质和较长歌曲可能需要数分钟到数十分钟，具体取决于电脑性能。

## 安装与启动

在 PowerShell 中进入项目目录，然后执行：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

浏览器打开：<http://127.0.0.1:7860/>

项目默认只监听本机地址 `127.0.0.1`。通常不需要单独安装 FFmpeg，`imageio-ffmpeg` 会提供视频编码所需的可执行文件。

如果 PowerShell 不允许执行激活脚本，也可以不激活环境，直接运行：

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

可通过环境变量修改监听地址和端口：

```powershell
$env:CLOUDMUSIC2KTV_HOST = "127.0.0.1"
$env:CLOUDMUSIC2KTV_PORT = "7860"
.venv\Scripts\python.exe app.py
```

## 使用方法

### 1. 登录网易云账号

在“01 网易云账号”中填写国家/地区代码和手机号，获取短信验证码后登录。

- 默认国家/地区代码为 `86`；
- 手机号和验证码不会写入磁盘；
- 登录成功后的网易云会话 Cookie 保存在 `instance/netease_cookies.json`；
- 点击“退出”会退出网易云会话并删除本地 Cookie 文件。

`netease_cookies.json` 相当于登录凭据，请勿分享或提交到公开仓库。

### 2. 选择歌曲

“02 选择歌曲”支持三种方式：

- 直接填写歌曲 ID，例如 `642810`；
- 填写网易云歌曲链接，例如 `https://music.163.com/#/song?id=642810`；
- 输入歌名、歌手进行搜索，然后点击正确的搜索结果。

修改 ID 输入框后必须点击“读取”或按 Enter 才会应用。03 区的“当前视频歌曲”会显示最后一次成功读取或点击选中的歌曲。页面刷新后会恢复最后选中的歌曲。

### 3. 下载全部素材

选择音质后点击“下载全部素材”。可选音质包括：

- 标准；
- 较高；
- 极高；
- 无损；
- Hi-Res。

实际返回的格式和音质由网易云及当前账号权益决定。程序会使用网易云返回的信息校验音频大小，并在可用时校验 MD5。

视频预览和生成都依赖本地素材，因此每首新歌必须先完成这一步。

### 4. 设置并预览视频

“03 生成 KTV 视频”提供以下选项：

- 歌词：仅原文、原文 + 翻译、原文 + 罗马音；
- 背景：封面模糊、封面配色渐变、纯色、自定义图片；
- 扫色：默认蓝色、自动匹配封面、自定义颜色；
- 分辨率：1920 × 1080 或 1280 × 720；
- 视频画质：高画质、平衡、较小文件；
- 是否显示动态频谱及其强度；
- 是否显示自动开场动画；
- 是否在间奏结束前显示歌词提示。

设置变化后会自动更新预览，也可以点击“更新预览”。预览和完整视频使用同一套 Python 帧渲染器。

自定义背景会保存到当前歌曲的输出目录，并在之后继续使用，直到再次上传覆盖它。图片上传上限为 32 MiB。

### 5. 生成完整视频

确认 03 区显示的“当前视频歌曲”正确，然后点击“生成完整视频”。

点击后，本次任务会立即锁定当时的歌曲和视频选项。生成期间可以在 02 区选择另一首歌，但新选择只影响下一次生成，不会改变正在运行的任务。

当前视频任务单线程执行；如果启动多个任务，后续任务会排队。生成期间请注意：

- 不要关闭运行 `app.py` 的终端；
- 不要重启后端服务；
- 刷新页面不会停止后台任务，但当前版本无法在刷新后恢复任务进度跟踪；
- 同一歌曲、同一分辨率再次生成会覆盖原来的对应 MP4 文件。

完成后，页面会显示文件路径和浏览器打开链接。

## 输出文件

每首歌曲保存在：

```text
outputs/<歌曲ID>_<歌手>_<歌名>/
```

目录可能包含：

```text
audio.mp3 / audio.flac / 其他实际音频格式
cover.jpg / cover.png
metadata.json
lyrics.lrc
lyrics_translated.lrc
lyrics_romanized.lrc
lyrics_karaoke_raw.lrc
lyrics_raw.json
lyrics_timeline.json
custom_background.png
spectrum_30fps.npz
video_preview.png
ktv_1080p.mp4 / ktv_720p.mp4
```

其中：

- `metadata.json`：标准化歌曲信息和网易云返回的音频信息；
- `lyrics_raw.json`：网易云歌词接口的原始响应，便于排查问题；
- `lyrics_timeline.json`：视频渲染使用的逐行毫秒时间轴；
- `spectrum_30fps.npz`：根据音频生成的频谱缓存；
- `video_preview.png`：当前设置生成的静态预览；
- `ktv_*.mp4`：最终视频。

## 歌词与间奏规则

网易云并非为每首歌提供逐字时间轴。本项目会优先使用带时间的逐行歌词，并在当前行的起止时间之间匀速扫色。

当前固定规则为：

- 相邻歌词开始时间超过 15 秒时视为间奏；
- 间奏中间不显示歌词；
- 上一句歌词扫色最长 8 秒；
- 下一段开始前 4 秒显示歌词与倒计时条；
- 开场动画为 4 秒；如果歌词开始过早，会在歌曲前添加 4 秒静音预卷并同步后移画面。

## 常见问题

### 预览提示“本地还没有这首歌的素材”

先在 02 区选择歌曲，然后点击“下载全部素材”。只读取歌曲信息并不会下载音频和歌词。

### VIP 歌曲无法取得完整音频

确认页面显示已登录，并确认该账号当前拥有这首歌的完整网页播放权益。退出后重新验证码登录也可能解决过期会话问题。

### 登录状态突然丢失

会话可能已过期，或 `instance/netease_cookies.json` 损坏。重新使用短信验证码登录即可。不要手工共享其他人的 Cookie。

### 视频生成很慢

逐帧画面由 Pillow 生成，再交给 FFmpeg 编码。可以选择 720p、“较小文件”，或关闭动态频谱来降低处理量。

### 中文或日文显示不正常

当前会依次使用 Windows 的微软雅黑、游ゴシック、Meiryo 等字体。请确认系统中存在可用的中日文字体。

### 网易云接口突然不可用

本项目使用网易云网页播放器所用的内部接口，这些接口可能随网站更新而变化。终端日志、`metadata.json` 和 `lyrics_raw.json` 可用于定位问题。
